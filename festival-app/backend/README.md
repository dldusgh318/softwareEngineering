# Festival Backend

대학 축제 통합 운영 플랫폼의 타임라인 API 서버입니다.

## Tech Stack

- Java 17
- Spring Boot 3
- Spring Web
- Maven

## API

- `GET /api/health`
- `GET /api/timeline`

## Run

IDE에서 `FestivalBackendApplication`을 실행하거나, 터미널에서 Maven으로 실행합니다.

```bash
cd backend
mvn spring-boot:run
```

## Build

```bash
cd backend
mvn package
```
